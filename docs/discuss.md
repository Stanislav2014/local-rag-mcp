## Q-01 Как сохранять историю запросов пользователя?

**Контекст:** пользователь явно попросил в сессии внедрения pipeline
(см. `session-prompts.md`). Сейчас всё уходит в stdout и теряется. Нужно
выбрать формат и место хранения.

### Варианты

| # | Вариант | Плюсы | Минусы |
|---|---|---|---|
| 1 | **JSONL append в `src/logs/queries.jsonl`** | просто, zero-dep, легко грепать / парсить | нет индексации, файл растёт |
| 2 | **SQLite таблица `queries(...)`** | индексация, join с метриками, SQL-запросы | +1 зависимость в коде (уже есть через faiss, но всё же) |
| 3 | **Отдельный ClickHouse / Loki** | профи-стек для логов | overkill для локального инструмента |

### Предварительный выбор
Вариант **1** (JSONL) — быстро получить ценность, совместимо с unix-tools.
Если понадобится метрика-dashboard (D-04), перейти на вариант 2 через миграцию.

### Статус
Open — становится задачей D-02.

## Q-02 `qwen3:0.6b` vs `qwen2.5:7b` как дефолт

**Контекст:** маленькая модель быстрая, но плохо работает с русским. Большая
модель качественная, но тянет 4.7 ГБ и медленная на dev-машине.

### Варианты

| # | Вариант | Плюсы | Минусы |
|---|---|---|---|
| 1 | **`qwen3:0.6b` по умолчанию + переключение через env** | быстрый cold start, минимум ресурсов | плохие ответы на русском |
| 2 | **`qwen2.5:7b` по умолчанию** | качественные ответы, особенно на русском | тяжелее, медленнее, 4.7 ГБ хранилища |
| 3 | **Профили `dev-small` / `ru-medium` / `prod-large` в config** | явный выбор, масштабируется | чуть больше конфигурации |

### Решение
Вариант **1** — явно выбран пользователем (сессия 2026-04-13). `qwen2.5:7b`
можно поднять через `OLLAMA_MODEL=qwen2.5:7b` env-override. В перспективе
перейти к варианту 3 (см. LW-007 в `legacy-warning.md`).

### Статус
Resolved — 2026-04-13. Обновлено в коде.

## Q-03 Сохранять ли `bm25.pkl` на диск?

**Контекст:** сейчас BM25-индекс строится в памяти при первом запросе после
старта (O(N) по чанкам). Для 24 чанков это несекунды, для 50K+ заметно.

### Варианты

| # | Вариант | Плюсы | Минусы |
|---|---|---|---|
| 1 | **Всегда строить в памяти** | нет риска рассинхрона c `chunks.pkl`, не нужно думать про версию формата | cold start медленнее |
| 2 | **Сохранять `bm25.pkl` рядом с `chunks.pkl`** | быстрый cold start | нужна логика инвалидации при пересборке индекса |
| 3 | **Lazy hybrid: для <1K чанков память, для больших — pickle** | оптимально по скорости и памяти | больше кода |

### Статус
Open — D-03 в tasks.md. Выбор отложен до появления корпуса >50K чанков.

## Q-04 Cross-encoder reranker: on-by-default или off?

**Контекст:** `BAAI/bge-reranker-base` весит ~400 MB. Включение даёт
+15-20% качества на зашумлённых корпусах. Но тянет время первого запроса.

### Варианты

| # | Вариант | Плюсы | Минусы |
|---|---|---|---|
| 1 | **Off по умолчанию, dev включает вручную** | быстрый первый запуск | новички не получают качество из коробки |
| 2 | **On по умолчанию** | качество из коробки | медленный первый запуск, больше RAM |
| 3 | **Отдельный образ `local-rag-mcp-app:full` с моделью** | чистое разделение dev / prod | больше поддерживать |

### Предварительное решение
Вариант **1** (текущее состояние). Включение явное — флаг в `config.py`.
Вариант 3 сделать когда будет prod-деплой.

### Статус
Open — C-08 (дизайн-решение, пока не задача).

## Q-05 Как именно расширять короткие русские запросы?

**Контекст:** LLM-rewrite для non-ASCII сейчас отключён полностью (маленькие
модели «переводили» в кривой английский). Но это значит, что для русских
коротких запросов expansion вообще не работает.

### Варианты

| # | Вариант | Плюсы | Минусы |
|---|---|---|---|
| 1 | **Ничего не делать — ждать `qwen2.5:7b`** | простота | длинные русские запросы без расширения |
| 2 | **Словарь русских аббревиатур** (`ип → индивидуальный предприниматель`, `ооо → общество с ограниченной ответственностью`) | offline, детерминированно | требует сборки словаря под домен |
| 3 | **LLM-rewrite с post-check: если ответ не на русском — откатить** | адаптивно | 1 доп. LLM вызов на каждый запрос |

### Статус
Open — C-03. Решение принять когда появится реальный русский корпус.
